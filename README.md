# Bazar-Dor

Bazar-Dor is a daily commodity market price tracking application where users can monitor real-time market prices, compare prices across different markets and divisions, track daily price rises and falls, and browse commodities by category in Bangladesh.

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- HeroUI
- Better Auth
- MongoDB
- react-fast-marquee
- react-hot-toast
- Lucide React

## Features

- Live commodity price ticker with real-time scrolling updates.
- Market-by-market price comparison tables showing minimum, maximum, and average prices.
- Track today's price risers and fallers with percentage change indicators.
- Browse and filter commodities across 8 essential food categories.
- Option C midpoint formula for accurate average price calculations.
- Native Bengali localization with Hind Siliguri typography and Bengali numeral conversion.
- User authentication with email/password and protected product details.
- User profile view and profile information update functionality.
- Responsive design for desktop, tablet, and mobile devices.
